# Remote work retreat industry dataset

Remote work removed the daily office requirement. It did not remove the need for trust, relationships, context, and occasional face-to-face time.

This repository structures the documentary research behind *I Investigated Why People Pay Thousands To Recreate The Office* into reusable datasets and citation-ready reference material.

**Canonical page:** https://jessicamalnik.com/resources/remote-work-retreat-industry/

**Documentary:** {{VIDEO_URL_NEEDED}}

## Dataset highlights

- 12 named retreat, travel, coliving, and workplace companies.
- 10 interview participants plus the documentary creator.
- 13 retreat-economy categories.
- 18 office functions mapped by post-remote status.
- 10 retreat value propositions.
- 7 business models.
- 16 market, company, and historical claims with verification labels.

## Central framework

1. Remove the daily obligation.
2. Retain digital coordination.
3. Identify the office value that disappeared by accident.
4. Rebuild only the valuable pieces through temporary gatherings.
5. Design those gatherings intentionally.
6. Return to distributed work.
